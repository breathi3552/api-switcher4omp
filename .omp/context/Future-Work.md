# 未实现债务与未来方向

本文是未实现工作、延后范围和当前非目标的唯一事实来源。它不描述已经实现的能力；已验证结果见 `Project-Overview.md` 与 `Verification-Register.md`，已接受架构决策见 `docs/adr/`。

## 产品方向

- 为每个供应商/分组配置独立用量，按分组计算成本。
- 补充币种、站内额度到人民币的换算，并按统一人民币成本推荐。
- 保存并浏览目标模型的完整分组价格，增加余额、价格历史、趋势、延迟和健康度等只读分析。
- 对供应商支持的接口增加账户分组实际验证，覆盖 Token 过期、401/403、Cloudflare、模型或分组下架等真实环境边界。
- 在明确用户授权后再考虑定时检查、通知、托盘和多模型加权。

## 网关和协议延后范围

- 多推理 API key 或 key 池。
- Chat Completions、Anthropic Messages 和跨协议转换。
- 独立运行状态详情、请求日志和用量统计。
- 运行中 OMP 实例列表或实例级路由。
- 自动切换、自动 fallback 和模型 fallback。
 - Issue #2 当前阻塞：需将固定 Bifrost v1.6.5 fork（含 Windows x64 二进制哈希校验）、单一私有 Named Pipe 控制协议、原子 `RouteSnapshot` 提交、按 `keyHandle` 的 Windows 安全存储解析、稳定无活动路由错误和 sidecar 生命周期监督接入生产；在此之前不得把应用层活动状态描述为真实 OMP 请求路由已完成。

## 当前非目标

- 不自动刷新、不开机联网检查、不定时执行，不用后台任务替用户选择供应商。
- 不把公开列出的分组当作 API key 权限证明，不通过未约定配置文件做候选过滤。
- 不进行全文件字符串替换，不修改 OMP 规定配置域之外的文本。
- 不自动回滚已成功的配置切换，不强制终止已有 OMP 进程。
- 当前不是账户管理、余额结算、充值汇率核算、日志核账或实际权限审计工具。

## 进入开发前的共同要求

- 先确认需求不是已有能力或已接受 ADR 的重复实现。
- 先定义用户可观察契约、失败和取消语义、凭据边界以及持久化/外部协议兼容策略。
- 先将工作拆成可验证的源码契约和隔离场景，再进入实现。
- 未经用户明确授权，不访问真实 Provider、真实凭据、真实用户数据或生产 OMP 配置。
