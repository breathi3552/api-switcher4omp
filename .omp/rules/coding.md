# 编码与安全规则

本文件只规定不会因文件移动或项目重组而改变的行为不变量。格式以 `.editorconfig` 和工具配置为准；当前实现入口以源码和 `AGENTS.md` 导航为准。

## 契约与模型

- 公共契约必须明确输入、输出、失败和取消语义；边界处验证空值、范围、格式、路径和协议。
- 优先使用不可变模型和只读集合；共享状态通过新实例更新，不原地修改。
- 身份、配置键和模型名使用明确的规范化与序数比较。
- 可预期失败使用结构化类型、枚举或结果，不用消息字符串分类；异常在边界映射为稳定状态。
- 异步操作传递 `CancellationToken`；不得同步阻塞等待或用 `async void` 承载可复用业务。

## 安全不变量

- Token、Cookie、API key、Authorization、密码和其他凭据不得进入设置、快照、日志、备份、异常文本、UI 回填、命令行或仓库。
- 凭据只能在必要的安全边界短暂存在，并使用安全存储。
- 日志和用户消息只包含脱敏、稳定、可行动的信息；不得记录完整请求/响应、查询参数或秘密。
- 凭据绑定不等于凭据有效；真实认证结果必须由实际探测以结构化状态表达。

## 持久化与副作用

- JSON 序列化和迁移集中在持久化边界；损坏或不支持的数据必须明确失败，不得伪装成空默认值。
- 写入先完成临时文件和 flush，再按既有原子替换/备份策略提交；失败不得留下部分写入。
- 设置、快照和凭据保持职责分离；失败刷新不得覆盖最后成功快照。
- 外部副作用必须可取消、可诊断、可清理，不得无限等待、静默重试或杀光同名进程。

## UI

- WPF 绑定必须有可追踪的 DataContext；ViewModel 通过 Application 契约工作。
- code-behind 只处理生命周期、纯视图交互、输入校验和确认，不复制业务编排。
- 异步命令必须防止重入，并在成功、失败、取消和关闭时恢复状态。
